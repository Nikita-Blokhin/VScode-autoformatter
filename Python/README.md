# Шаблон для инициализации проекта на языке TypeScript/JavaScript

#### ВНИМАНИЕ

Просмотрите README.md в корне проекта для установки необходимых расширений и настройки своей среды разработки

#### Для создания Django проекта

Создать виртуальное окружение (это важно, чтобы зависимости проекта не конфликтовали с системными):

```bash
python -m venv venv
```

Инициализация Django проекта:

1. Установить Django:

```bash

pip install django
```

2. Создать проект (например, с именем mysite):

```bash

django-admin startproject mysite
```
